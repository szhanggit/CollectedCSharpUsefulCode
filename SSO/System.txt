Deploy SSO

1. Create an admin account 
Go to the application pool,
i.	Set 'Enable 32-Bit Applications' to be true.
ii. 	Set Identity to be the admin account created above.
iii.	Set 'Load User Profile' to be true. 

2. Go mmc, find the certificate you use, right click, All tasks, manage private keys. Add the admin account created above.

3. In the IIS site, select the root note right below Start Page.
Double click Server Certificates under IIS.
Double click the certificate you use, and select details.
Get Subject Info
like: 
E = knight.yao@edenred.com
CN = *.edenred.net
OU = IT
O = Edenred Pte Ltd
L = Shanghai
S = Shanghai
C = CN

Get Thumb Print Info, !! need to fill it in web.config (delete all of the space among strings.)
like: ‎f3 e8 25 dc 37 c6 08 a8 f8 f4 1a 88 78 e0 dd d4 4c bb 07 55
