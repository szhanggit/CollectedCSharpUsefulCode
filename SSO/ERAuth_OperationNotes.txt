Add an application:
Application Manager -> Application List -> Create
(After creating, you will get Name, Key)
__________________________________________________________________
Go to Mo Web web.config, find: 
ERAuth.AppName = Name
ERAuth.AppKey = Key
__________________________________________________________________
Add privilege:
Application Manager -> Role Management -> Application Roles
__________________________________________________________________
Add menu:
Application Manager -> Menu Management -> Application Menus -> Select an item -> check a role and click save.
__________________________________________________________________
Add resource list:
Application Manager -> Resource Management -> Resource Management 
__________________________________________________________________
Add operation:
Application Manager -> Operation Management -> Operation Management 
__________________________________________________________________
Permission setting:
Application Manager -> Permission Management -> Permission Management  
__________________________________________________________________
Edit User Managerment
User Management -> User List -> Find a user to edit App-> Check the app which you just created.
__________________________________________________________________
Identity Server Management -> Fill name, Realm, and ReplyTo. //Pay attention for the format. It must have http:// and end with /.
